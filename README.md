# S&DS 265 / 565 — Introductory Machine Learning

Yale University, Fall 2026. Slides, demo notebooks, and the course website.

- **Course page:** https://zhuoranyang.github.io/sds265-fall26/
- **Canvas** carries the syllabus, announcements, grades, and submission.

## What is here

    lectures/     one PDF per lecture
    demos/        one folder per lecture: a notebook and the data it reads

Demo notebooks appear here as they are confirmed during the term, so `demos/`
fills in week by week while `lectures/` is complete from the start.

Every notebook reads its data by filename from its own folder, so it runs in
Google Colab with nothing to install and nothing to download. Open one from the
course page, or prefix its GitHub path with
`https://colab.research.google.com/github/`.

## Data

`demos/*/` contains course copies of the ISLP data sets, downloaded unmodified
from <https://www.statlearning.com/>. Cite James, Witten, Hastie, Tibshirani,
and Taylor, *An Introduction to Statistical Learning with Applications in
Python* (Springer, 2023) when using them.
