background for the notebook; content is unchanged. The slides use PDF conversions
of the same SVGs. These figure files retain CC BY-SA 4.0. The notebook's explanations
use $F$ for the residual branch called $g$ in D2L's plain/residual diagram.
TorchVision's projection shortcut additionally contains batch normalization.
